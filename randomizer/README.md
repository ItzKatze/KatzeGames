# Randomizer

Break a block and see what you get. Drops and loot are replaced with other items,
so finding a useful source becomes part of survival.

Mappings stay consistent during a round: once you discover what a block drops, you can come back for more.

## Settings

Operators can toggle each option in `/settings`.

| Setting | What changes | Default |
| --- | --- | --- |
| Block drops | Items dropped when you break blocks. | On |
| Mob drops | Items dropped by mobs. | Off |
| Chest loot | Items generated by loot tables. | On |
| Shared mappings | Everyone uses the same replacements. | On |

Turn **shared mappings off** for personal replacements. A discovery that helps you may not help your friend.
