# Randomizer

Break a block and see what you get. Drops and loot are replaced with other items,
so finding a useful source becomes part of survival.

Each original item has one replacement during a round, keeping its original count.
Coal from ore, chests, and mobs uses the same replacement. Dirt and grass blocks also
give the same item when both would normally drop dirt. Explosions randomize block drops,
while items stored inside broken containers keep their contents.

## Settings

Operators can toggle each option in `/settings`.

| Setting | What changes | Default |
| --- | --- | --- |
| Block drops | Items dropped by mining, explosions, and other block breaks. | On |
| Mob drops | Items dropped by mobs. | Off |
| Chest loot | Items generated by loot tables. | On |
| Shared mappings | Everyone uses the same replacements. | On |
| Team mappings | Each team shares its own replacements, overriding shared mappings. | Off |

Turn **shared mappings off** for personal replacements. A discovery that helps you may not help your friend.
With **team mappings on**, teammates share discoveries and players without a team use personal replacements.
Drops without a responsible player use the global replacements.
