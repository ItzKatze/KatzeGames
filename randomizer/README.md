# Randomizer

Discover which blocks and loot sources give you the items you need.

## How drops work

- Each original item has **one consistent replacement** during the round, keeping its original count.
- The same original item gives the same replacement across enabled sources.
- **Block drops and chest loot** are randomized by default; mob drops may also be enabled.
- Items already stored inside containers keep their contents when the container breaks.

## Share your discoveries

| Round rules | Who gets the same replacements?                                |
|-------------|----------------------------------------------------------------|
| Shared      | Everyone; this is the default.                                 |
| Personal    | Each player has their own replacements.                        |
| Team        | Teammates share replacements; unteamed players have their own. |

Remember useful sources and share them with players who use the same replacements.

## Settings

| Setting             | What changes                                                             | Default |
|---------------------|--------------------------------------------------------------------------|---------|
| Block drops         | Randomize items dropped when blocks break.                               | On      |
| Mob drops           | Randomize items dropped by mobs.                                         | Off     |
| Chest loot          | Randomize generated chest loot.                                          | On      |
| Shared replacements | Give everyone the same replacements; turn off for personal replacements. | On      |
| Team replacements   | Give each team its own replacements, overriding shared replacements.     | Off     |
